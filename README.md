# The Meeting That Should Have Been One Line

A [make.fun](https://make.fun/bounty/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c) entry: one sentence that could have replaced an entire pointless meeting. No context, no explanation, just the line that kills the meeting.

> We booked a room, six calendars, and an hour of everyone's lives to answer a question that a one-word email saying yes would have settled before lunch.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt`. Deterministic: the same 151 characters every run, well under the 200-character gate.
